# Smart Knowledge Assistant

A Retrieval Augmented Generation (RAG) application built using:

- Streamlit
- ChromaDB
- Hugging Face Embeddings
- Hugging Face LLM
- Semantic Search
- PDF Knowledge Base

## Features

- PDF Upload
- Automatic Chunking
- Embedding Generation
- ChromaDB Vector Storage
- Semantic Retrieval
- LLM Question Answering
- Source Attribution

## Architecture

PDF
→ Chunking
→ Embeddings
→ ChromaDB
→ Retrieval
→ LLM
→ Answer
